# نقطة بيع — نادي حصارات الرياضي الثقافي الاجتماعي

تطبيق نقطة بيع بقسائم للأكشاك، يعمل بلا إنترنت، بالدولار والليرة.

## التشغيل من الرابط
بعد تفعيل GitHub Pages يصبح الرابط:
`https://dhoyek.github.io/hsarat-pos/`

افتحه من الهاتف مرة واحدة، ثم أضفه إلى الشاشة الرئيسية. بعدها يعمل بلا إنترنت.

## التشغيل بلا رفع
افتح `index.html` مباشرةً بأي متصفح.

## البيانات
تُحفظ داخل متصفح الجهاز فقط — لا شيء يُرفع إلى الإنترنت.
احفظ نسخة احتياطية من الإعدادات بعد كل وردية.
